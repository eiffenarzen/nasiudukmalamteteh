# Nasi Uduk Malam Teteh 🍚🌙

Website profil lapak **Nasi Uduk Malam Teteh** - Gurihnya Hangat, Malamnya Berasa Rumah.

## 🌐 Akses Online (GitHub Pages)

Website ini aktif 24/7 dan bisa diakses langsung lewat HP maupun laptop tanpa perlu menyalakan server lokal:
👉 **[https://eiffenarzen.github.io/nasiudukmalamteteh/](https://eiffenarzen.github.io/nasiudukmalamteteh/)**

## 📁 Struktur Berkas

- `index.html` : Halaman web utama (versi statis untuk GitHub Pages).
- `index.php` : Halaman web dinamis PHP (untuk Laragon / server lokal).
- `config.php` : Konfigurasi data warung (menu, harga, kontak, medsos).
- `assets/` : Gambar (`logo.png`) dan berkas gaya tampilan (`css/style.css`).
- `includes/` : Komponen header, footer, dan fungsi helper PHP.

## 🛠️ Cara Edit Konten
- Jika mengedit versi online (GitHub Pages): cukup ubah berkas `index.html`.
- Jika mengedit versi lokal PHP (Laragon): ubah berkas `config.php`.
